# 갖고 계신 자료 가져오기 (10~20분)

> 새로 쓰는 것보다 **이미 있는 것을 가져오는 게 훨씬 빠릅니다.** 예전에 쓴 서류 한 장, 다른 AI랑 나눈 대화 하나면 충분합니다.
> 전부 다 하지 않아도 됩니다. **하나만 해도 다음부터 달라집니다.**

## 1. 예전에 쓴 서류·글

바탕화면이든 메일함이든, 있는 걸 그대로 AI에게 주면 됩니다.

- 지난 지원사업 신청서·사업계획서 → **양식과 문장이 통째로 재료가 됩니다**
- 회사·가게 소개글, 홍보 문구 → 말투를 배우는 데 씁니다
- 정산서·매출표·활동 사진 → 숫자의 근거가 됩니다

AI에게 이렇게 말하세요:

> 예전에 쓴 파일이 있어요. 이거 보고 **역방향 모드**로 카드 만들어 줘.

## 2. 다른 AI와 나눈 대화 가져오기

챗지피티나 다른 AI에게 사업 얘기를 해두셨다면, 그게 이미 자산입니다.

**방법 A — 통째로 내보내기**
- ChatGPT: 설정 → 데이터 제어 → 데이터 내보내기 → 메일로 받은 파일 압축 해제 → `conversations.json`
- Claude: 설정 → 계정 → 데이터 내보내기
- 받은 파일을 AI에게 주면서: *"여기서 내 사업 관련된 사실만 뽑아서 카드로 만들어 줘. 없는 건 지어내지 말고."*

**방법 B — 복사해서 붙여넣기 (더 쉽습니다)**
쓸 만한 대화를 열어서 **그 부분만 긁어다 붙여넣으세요.** 전부 가져올 필요 없습니다.

**방법 C — 다른 AI에게 요약을 시켜서 가져오기**
그 AI에게 먼저 이렇게 시키세요:
> 지금까지 내 사업에 대해 나눈 얘기에서 **사실만** 목록으로 정리해 줘. 숫자는 출처도 같이. 확실하지 않은 건 「미확인」이라고 표시해.

그 결과를 이쪽에 붙여넣으면 됩니다.

## 3. 가져올 때 지켜야 할 것

- **AI가 요약한 내용은 사실이 아닙니다.** 그건 다시 확인해야 하는 후보입니다. 카드 등급이 `unknown`으로 시작하는 이유입니다.
- **개인정보는 빼고 주세요** — 주민번호·계좌번호·손님 연락처. 지우고 주셔도 나머지는 다 쓸 수 있습니다.
- 다른 사람이 쓴 글(남의 제안서·기관 자료)은 **참고만** 하고 문장을 그대로 옮기지 않습니다.

## 4. 가져온 뒤

AI가 `me/assets.md` 에 **무엇을 어디서 가져왔는지만** 적어 둡니다. 내용은 옮기지 않습니다.
그다음부터는 매번 처음부터 설명하지 않으셔도 됩니다.
