# SAMPLE 골격 초안 — 카드 표기·검사 표시가 붙은 모습

> 가상 공고(`forms/sample-form.md`) 항목 2「사업 성과」·항목 3「성장 전략」의 골격. 전부 가짜 데이터. 대괄호 표기는 제출 직전에 뗍니다(떼기 전 판 보관).

## 2. 사업 성과 (1p)
SAMPLE 로컬브루잉 협동조합[c-01]은 2023년 3월 설립된 조합원 9명[c-01]의 협동조합이다. 2025년 매장 방문객은 월평균 1,240명[c-02]이었고, 2026년 상반기에 지역 청년 3명[c-03](바리스타 2·로스팅 1)을 채용했다.

**검사 표시**: 숫자 5개 전부 카드 있음 · c-03은 user_reported — 4대보험 확인서 첨부 시 verified로 올라감(제출 전 숙제).

## 3. 성장 전략 (2p)
2026년 4분기 신메뉴 2종을 출시한다. 출시 시 월 방문객이 10% 늘 것으로 **가정하며**[c-04], 출시 2개월 후 POS 집계로 실측해 가정을 검증한다.

~~고양시 20대 인구가 줄고 있어 청년 유입 거점이 필요하다~~ → **이 문장은 뺐다.** 근거 카드 c-05가 `unknown`(KOSIS 미확인)이라 본문에 못 쓴다. 확인되면 되살린다.

**검사 표시**: assumed 카드 문장 = "가정하며"로 표기 ✓ · unknown 의존 문장 = 제거 ✓ · 측정 방법 명시 ✓.

### 이 예시가 보여 주는 것 3개
1. 숫자마다 `[c-XX]` — 어디서 왔는지 문서 스스로 말한다.
2. 가정은 가정이라고 쓴다 — 심사 Q&A에서 "근거는요?"에 "가정이고, 이렇게 검증합니다"로 답이 준비된다.
3. 근거 없는 문장은 지운 흔적째 남긴다 — 카드가 생기면 되살린다.
