# proposal-lane — 근거부터 쌓는 제안서 작업 폴더

처음 오셨다면 `FIRST-RUN.md`를 여세요 — 30분 안에 내 소재로 한 바퀴 돕니다.

제안서·지원사업 신청서를 쓸 때, **주장을 쓰기 전에 근거 카드부터** 만들고, 모든 숫자와 고유명사 뒤에 카드 번호를 붙이는 작업 방식입니다. 초안은 AI가 도와도, **근거 없는 문장은 근거 없다고 표시된 채로** 나옵니다. 심사 Q&A에서 무너지는 건 문장력이 부족한 문서보다 근거 없는 숫자가 든 문서라서요.

> 부엌에 비유하면: 근거 카드 = 재료, 이 폴더 = 냉장고, 공고 양식 = 레시피, 제출 전 검사 = 맛보기. 비유는 여기까지만 쓰고, 파일 이름은 전부 그대로 읽히는 말로 되어 있어요.

**필요한 것**: 이 폴더(md 파일 묶음) + 아무 AI 챗(웹 ChatGPT·Claude·Gemini 포함). Obsidian이나 터미널이 있으면 더 편하지만 없어도 됩니다.

## 5분 시작 (마감이 급하면 B부터)

### A. 순방향 — 시간이 있을 때
1. `forms/FORM-TEMPLATE.md`를 복사해 공고 양식을 옮겨 적어요(항목·페이지 제한·표 고정 여부·평가 기준). **공고 원문 파일을 못 열었으면 여기서 멈추고 먼저 구해요.**
2. `cards/CARD-TEMPLATE.md`를 복사해 근거 카드를 만들어요. 카드 1장 = 주장할 수 있는 사실 1개 + 어디서 확인했는지 + 등급.
3. AI 챗에 `PROTOCOL.md` 전문을 붙여 넣고, 양식과 카드를 주고 골격 초안을 요청해요.
4. `checks/submit-check.md`로 5분 검사 → HWP에 옮긴 뒤 **최종본에서 한 번 더** 숫자를 대조해요.

### B. 역방향 — 이미 초안이 있거나 마감이 급할 때
1. 초안(또는 머릿속 내용을 쏟아낸 글)을 AI에 주고 `PROTOCOL.md`의 **역방향 모드**를 요청해요: AI가 초안에서 주장·숫자를 뽑아 **전부 `unknown` 등급 카드**로 만들어 줍니다.
2. 카드 목록이 곧 숙제 목록이에요. 확인한 것부터 등급을 올리고, 못 올린 카드의 문장은 고치거나 "추정"이라고 적어요.
3. 4번(검사)은 동일.

## 완성 예시 먼저 보기
가상 지원사업 1건의 완성 세트가 들어 있어요 — 이름·숫자 전부 가짜(SAMPLE)입니다.
- 채워진 양식: `forms/sample-form.md`
- 근거 카드 5장: `cards/sample/`
- 카드 번호가 붙은 골격 + 검사 표시: `samples/sample-draft.md`

## 먼저 알아야 할 것 — 대신 써 주는 도구가 아닙니다

정부·지자체 지원사업은 **사업계획서를 제3자가 대신 써 주는 것을 부정수급으로 다룹니다.** 적발되면 지원금 전액 환수와 향후 사업 참여 제한까지 갑니다(중소벤처기업부, 브로커 실태점검 연 2회). 규제가 보는 것은 「AI를 썼는가」가 아니라 **「본인이 쓴 것이 맞는가」** 입니다.

이 킷이 말투를 보존하고, 근거를 당신이 대는 카드로만 만들고, AI에게 다듬기를 시키지 않는 이유가 그것입니다. **근거 카드는 「내가 썼다」는 증거이기도 합니다.** 반대로 AI에게 통째로 맡겨 받은 문서를 그대로 내는 것은 이 킷의 사용법이 아닙니다.

지원하려는 공고문의 **부정행위·대리작성 조항을 먼저 읽으세요.** 기관마다 다릅니다.

## 솔직한 안내
- 이 폴더는 검사를 **자동으로** 해 주지 않아요. 검사 목록을 짧게(숫자·고유명사만) 만든 이유예요.
- 국내 지원사업 최종 제출은 대부분 HWP 서식(페이지 제한·표 고정)이에요. **markdown에서 통과한 검사는 HWP로 옮기는 순간 다시 해야** 유효합니다 — 검사표 마지막 항목이 그것입니다.
- 카드를 쌓는 일 자체가 목표는 아니에요. **제안서 1건을 쓰고 나면 카드가 부산물로 남고**, 다음 제안서가 그걸 물려받으면서 점점 빨라집니다.
