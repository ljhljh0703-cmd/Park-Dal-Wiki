# FIRST-RUN — 처음 앉은 자리에서 내 제안서 만들기 (30~40분)

> 이 문서 하나만 따라가면 됩니다. 오늘의 목표는 **내 소재로 카드 몇 장 + 카드 번호가 붙은 골격 초안**까지 가 보는 것(완성본은 다음 일). 문체는 당신 것을 그대로 씁니다 — AI가 말투를 바꾸지 않게 하는 지시가 아래에 들어 있어요.

## 준비물 (시작 전 2분)
- 노트북 + 평소 쓰는 AI 챗 아무거나(웹 ChatGPT·Claude·Gemini — 로그인만 되어 있으면 됩니다)
- **내 소재 1개** — 아래 중 하나면 충분:
  - 예전에 썼던 제안서·사업계획서 파일 (가장 좋음)
  - 지금 준비 중인 공고 파일(HWP·PDF)
  - 둘 다 없으면: 하고 싶은 사업 이야기를 말로 5분 쏟아낼 준비

## 0단계 — 설치 (5분)
1. 이 폴더(`proposal-lane`)를 받습니다 — 아래 주소를 브라우저 주소창에 넣으면 16KB짜리 파일 하나가 받아집니다. 압축을 풀면 끝입니다.
   ```
   https://github.com/ljhljh0703-cmd/Park-Dal-Wiki/raw/main/proposal-lane.zip
   ```
   (이미 폴더로 받았거나 저장소 전체를 받았다면 그 안의 `proposal-lane` 폴더만 쓰면 됩니다.)
2. 끝입니다. 설치할 프로그램이 없어요. 메모장으로도 열리는 텍스트 파일 묶음입니다.
3. 30초 훑기: `samples/sample-draft.md`를 열어 **완성되면 어떤 모양인지**만 봅니다 — 숫자마다 `[c-01]` 같은 꼬리표가 붙어 있죠. 오늘 만들 게 저겁니다.

## 1단계 — AI에게 규약 주기 (2분)
AI 챗을 열고, `PROTOCOL.md` 파일 내용 전체를 복사해 붙여 넣습니다. 그 아래에 이렇게 한 줄 덧붙이세요:

> 그리고 내 문장의 말투와 어순은 고치지 마. 너는 카드 만들기, 꼬리표 붙이기, 빠진 근거 알려주기만 해. **제안서는 내 목소리로 쓴다.**

## 2단계 — 내 소재 쏟아내기 (10분, 역방향 모드)
셋 중 하나:
- **지난 제안서가 있으면**: 본문을 붙여 넣고 → "역방향 모드로 해 줘"
- **공고만 있으면**: 공고의 항목 목록을 붙여 넣고 → "이 양식을 `forms/FORM-TEMPLATE.md` 틀로 정리해 줘. 그리고 내가 말로 소재를 줄게" → 사업 이야기를 편하게 타이핑
- **둘 다 없으면**: 그냥 이야기하세요 — "우리는 ○○를 하는 팀이고, 작년에 △△했고, 이번에 □□를 하려고 해" → "역방향 모드로 해 줘"

AI가 당신 이야기에서 **주장·숫자를 뽑아 카드 목록**으로 돌려줍니다 — 전부 `unknown` 등급으로. 이게 정상이에요. 아직 아무것도 증명 안 했으니까.

## 3단계 — 카드 3장만 등급 올리기 (8분)
카드 목록에서 **가장 자신 있는 3장**을 고르세요. 각각에 대해:
- 어디서 확인할 수 있는지 적는다 (통장·계약서·정산서·사진·등기부 — 지금 파일이 없어도 "어디에 있는지"만)
- 서류로 지금 확인 가능하면 → `verified`
- 내가 겪어서 아는 거면 → `user_reported`
- **겪긴 했는데 정확한 숫자가 기억뿐이면 → `recalled`** (제일 흔합니다. "서른 몇 가구"를 억지로 34로 만들지 마세요)
- 확인 못 하지만 꼭 쓸 거면 → `assumed`(문장은 "가정"으로)

AI에게: "이 3장 등급 갱신하고, 카드 파일 형식(`cards/CARD-TEMPLATE.md`)으로 만들어 줘" → 받은 내용을 `cards/` 폴더에 파일로 저장.

## 4단계 — 골격 초안 (10분)
AI에게: **"이 카드들로 골격 초안을 써 줘. 양식은 [2단계에서 만든 양식 / 없으면 forms/emergency-form.md]. 내 말투 유지, 모든 숫자·고유명사 뒤에 꼬리표."**

받은 초안에서 확인할 것 두 가지뿐:
- `[unknown]` 꼬리표가 몇 개인가 → 그게 **당신의 숙제 목록**입니다 (오늘 다 못 올려도 됩니다)
- 내 말투가 맞나 → 아니면 "3번째 문단, 내가 쓴 원래 문장으로 되돌려" 라고 하면 됩니다

## 5단계 — 마무리 검사 (5분)
AI에게: **"리허설 — 심사위원이 이 문서에서 무너뜨릴 문장 3개만 뽑아 줘."**
그 3문장이 오늘의 수확입니다: 제출 전에 고치거나, 근거를 만들거나, 가정이라고 적으면 되는 지점.
