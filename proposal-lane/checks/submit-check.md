# 제출 전 검사 (5분) + 심사 Q&A 리허설

> 짧아야 실제로 합니다. 검사 대상은 **숫자와 고유명사만** — 문단 전체 대조는 도구가 생기기 전엔 사람 일이 아닙니다.

> 🤖 = AI에게 시킬 수 있음 · 🙋 = **사람만 가능**(AI가 "검사했습니다"라고 해도 이건 안 된 것입니다)

## 1. 숫자·고유명사 검사 (초안에서) 🤖
- [ ] 초안의 모든 숫자 뒤에 `[c-XX]` 또는 `[unknown]`이 붙어 있다 (없는 숫자 = AI 또는 내가 지어낸 것)
- [ ] **표기가 아예 없는 문장을 따로 훑었다** — AI에게 "대괄호가 하나도 없는 문장만 그대로 뽑아 줘"라고 시키세요. 위 항목은 표기가 *붙은* 것만 보게 돼서, 통째로 빠진 문장이 제일 잘 새어 나갑니다
- [ ] 🔴 **표기가 붙은 숫자를 카드 본문과 한 개씩 대조했다** — 그 숫자가 그 카드 안에 **글자 그대로 있는지**. 없으면 지어낸 숫자에 남의 카드 번호를 얹은 것이고, 이건 `[unknown]`보다 나쁩니다(근거가 있다고 표시된 거짓). 위 항목만으로는 절대 안 잡힙니다.
- [ ] 카드 하나가 여러 문장에 붙어 있다면, **그 문장들이 정말 그 카드 하나로 다 커버되는지** 봤다
- [ ] `[unknown]`이 붙은 문장을 하나씩 결정했다: 카드 등급을 올렸다 / 문장을 뺐다 / "추정"으로 고쳤다
- [ ] **카드의 등급과 출처 칸이 서로 맞는다** — 출처가 "기억"인데 등급이 `user_reported`면 `recalled`가 맞습니다. 등급은 출처보다 높을 수 없습니다
- [ ] `assumed` 카드에 기댄 문장이 전부 "가정한다·추정된다"로 쓰여 있다 (단정형 0)
- [ ] `recalled` 카드에 기댄 숫자가 **범위 표기**로 쓰여 있다("약 30가구대") · 정확한 값으로 둔갑하지 않았다
- [ ] 합계·비율을 계산기로 1번 재계산했다 (분모가 1~2인 비율·배수는 쓰지 않았다)
- [ ] **분모가 문서에 안 보이는 비율**(예: "관내의 12%")이 없다 — 분모 카드가 없으면 그 비율은 못 씁니다
- [ ] 기관명·통계 이름을 카드와 글자 단위로 대조했다
- [ ] 🙋 **법 조항·통계는 카드가 아니라 원문 DB에서 확인했다** (법령은 law.go.kr에서 조 번호를 직접 열어 내용까지 봅니다). 카드 대조만으로는 "조항 번호 자체가 틀린 경우"를 절대 못 잡습니다 — 실측에서 「제18조에 근거한다」의 제18조가 인증취소 조항이었습니다

## 2. 양식 검사 🙋 (공고 원문을 열어야 함)
- [ ] 양식 파일에 `⚠ 원문 미대조` 표시가 남아 있지 않다
- [ ] 항목 이름·순서가 공고 원문과 같다 (emergency-form으로 끝내지 않았다)
- [ ] 항목별 분량 제한 안에 있다
- [ ] 요구 제출 서류 목록을 다시 열어 빠진 첨부가 없다

## 3. 최종본 검사 — HWP(또는 시스템 입력)에 옮긴 뒤 🙋 (전부 사람 일입니다)
- [ ] **붙여넣기 후 최종본에서** 숫자를 카드와 다시 대조했다 (분량 맞추며 고친 숫자가 제일 위험)
- [ ] 대괄호 표기 `[c-XX]`·`[unknown]`를 제출본에서 제거했다 (제거 전 판은 보관)
- [ ] 표 고정 항목을 건드리지 않았다 · 지정 글꼴/크기 유지
- [ ] 저장 후 다시 열어 확인했다 (제출 영수증·화면 캡처까지)

## 4. 심사 Q&A 리허설 🤖 (AI에게: "리허설")
AI에게 최종본을 주고 요청하세요: **"심사위원이 이 문서에서 무너뜨릴 문장 10개를 뽑고, 각각 어떤 질문이 올지, 지금 카드로 답할 수 있는지 표시해 줘."**
- 답 못 하는 문장이 남아 있으면 → 그 문장을 빼거나, 가정으로 고치거나, 카드를 만들 시간이 있는지 봅니다.
- 리허설 결과는 발표·면접 대비 자료로 그대로 씁니다.
